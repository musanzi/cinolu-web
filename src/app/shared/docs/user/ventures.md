# User — Ventures

| Feature          | Route                      | Params                                                                                                               | Body                                                                                                            | Response                      |
| ---------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| Create venture   | `POST /ventures`           | None                                                                                                                 | `name: string` (max 150), `description: string`, `socials?: object`, `stage: VentureStage`, `sectorIds: UUID[]` | `Venture`                     |
| List my ventures | `GET /ventures/mine`       | Query: `page?`, `limit?`, `take?`, `q?: string`, `sectorId?: UUID`, `stage?: VentureStage`, `status?: VentureStatus` | None                                                                                                            | `[Venture[], number]`         |
| Get my venture   | `GET /ventures/mine/:id`   | Path: `id: UUID`                                                                                                     | None                                                                                                            | `Venture`; ownership enforced |
| Upload logo      | `POST /ventures/:id/logo`  | Path: `id: UUID`                                                                                                     | Multipart: `logo: file`                                                                                         | `Venture`; ownership enforced |
| Upload cover     | `POST /ventures/:id/cover` | Path: `id: UUID`                                                                                                     | Multipart: `cover: file`                                                                                        | `Venture`; ownership enforced |
| Update venture   | `PATCH /ventures/:id`      | Path: `id: UUID`                                                                                                     | Any create field, optional                                                                                      | `Venture`; ownership enforced |
| Delete venture   | `DELETE /ventures/:id`     | Path: `id: UUID`                                                                                                     | None                                                                                                            | `void`; ownership enforced    |

`VentureStage` is `idea | mvp | early_stage | growth | mature`. `VentureStatus` is `pending | approved | rejected`. `Venture` contains the base entity fields plus `name`, `slug`, `logo?`, `cover?`, `description`, `socials`, `owner`, `stage`, `status`, and `sectors`. Editing an approved or rejected venture resets its status to `pending`.
