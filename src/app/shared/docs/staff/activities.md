# STAFF — Activities

| Feature             | Route                               | Params                                                                                        | Body                                                                                                                                                                                                                                                       | Response               |
| ------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| Create activity     | `POST /activities`                  | None                                                                                          | `name: string` (max 150), `description?: string`, `startDate: DateTime`, `endDate: DateTime`, `participationForm: object`, `isPublished?: boolean`, `reviewForm: object`, `programId: UUID`, `mentorIds: UUID[]`, `typeIds: UUID[]`, `categoryIds: UUID[]` | `Activity`             |
| List all activities | `GET /activities/staff`             | Query: `page?`, `limit?`, `take?`, `q?: string`, `startDate?: DateTime`, `endDate?: DateTime` | None                                                                                                                                                                                                                                                       | `[Activity[], number]` |
| Get activity by ID  | `GET /activities/staff/:id`         | Path: `id: UUID`                                                                              | None                                                                                                                                                                                                                                                       | `Activity`             |
| Upload cover        | `POST /activities/:id/cover`        | Path: `id: UUID`                                                                              | Multipart: `cover: file`                                                                                                                                                                                                                                   | `Activity`             |
| Toggle publication  | `PATCH /activities/:id/publication` | Path: `id: UUID`                                                                              | None                                                                                                                                                                                                                                                       | `Activity`             |
| Update activity     | `PATCH /activities/:id`             | Path: `id: UUID`                                                                              | Any create field, optional                                                                                                                                                                                                                                 | `Activity`             |
| Delete activity     | `DELETE /activities/:id`            | Path: `id: UUID`                                                                              | None                                                                                                                                                                                                                                                       | `void`                 |

`Activity` includes its base entity fields plus `name`, `slug`, `description?`, `startDate`, `endDate`, `participationForm`, `isPublished`, `reviewForm`, `cover?`, `program`, `mentors`, `types`, and `categories`.
